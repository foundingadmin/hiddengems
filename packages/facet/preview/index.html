Gray by default, and every hue has one job

Each band is a hue's whole contract: its job, its ten step scale, and the semantic tokens that draw from each step. Product code uses the semantic token, never the step itself. Every step is redefined for dark mode and wide-gamut screens, so a token stays correct in both themes.

Color always travels with a second cue

A hue only confirms what the shape or the word already says, so the screen still reads for color-blind users, in grayscale and in print.
