# apps/web (placeholder)

The Hidden Gems Next.js app lands here when the UI work migrates in. It consumes the design
system as a workspace package (`@foundingcreative/facet`) and deploys on Vercel with this folder
as the project's Root Directory. See `/docs/vercel-deployment.md`.

The full scaffold for data, ingestion, history, logs and API integrations is Phase 2 of the plan
and is intentionally not created yet.
