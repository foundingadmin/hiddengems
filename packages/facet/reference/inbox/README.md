# Inbox

Drop third-party and inspiration material here: Vercel screenshots (paid app and marketing),
jumpstart markdown files, notes. Suggested layout:

```
inbox/
  screenshots/vercel-app/        Your Vercel dashboard screens
  screenshots/vercel-marketing/  Public marketing pages
  jumpstart/                     Third-party DS starter files
```

Material here is rank 4 in SOURCES.md: ideas only. When something here conflicts with
vercel.com (tokens, measurements, Geist docs), vercel.com wins. Processed findings move into
foundations/, components/ or patterns/ with a note on where they came from.
