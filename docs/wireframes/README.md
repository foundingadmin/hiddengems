# Wireframes

Approved screens for Hidden Gems v1, Nov 2 2026. Build spec in [`../build-brief.md`](../build-brief.md).

- `*.dc.html`: board source from the design canvas, Facet classes only. They link `ds/facet/…` (the canvas's copy of Facet) and `hg-wire.css`, so they render on the canvas, not standalone from this folder.
- `png/`: a render of each board.
- `canvas.json`: canvas layout and board titles.
- The design canvas they were drawn on is retired. These files are the wireframes.

Desktop: `DesktopMain`, `DesktopGem`, `DesktopJeweler`, `DesktopSlip`, `DesktopSlipChange`, `DesktopHandoff`, `DesktopSlipHistory`, `DesktopResult`.
Phone: `Main`, `Gem`, `Jeweler`, `Slip`, `SlipChange`, `Handoff`, `SlipHistory`, `Result`.
