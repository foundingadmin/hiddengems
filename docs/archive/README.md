# Archive

Pages and data that used to live in claude.ai artifacts, saved here as they were on Nov 3 2026. They are history, not specs: where they disagree with `docs/prd.md`, the PRD wins.

| File | What it was |
|---|---|
| `lookbook.html` | Feature lookbook: competitor research, feature cards priced in build hours, the color wheel and palettes, the Jeweler's bench. |
| `pipeline/picks.json` | The old pipeline's picks history: 146 anytime TD props (Week 8 pilot and board, Week 9 opening board) with Outlier prices, frozen reads, closes and grades, as of Nov 2 2026. |
| `pipeline/scorecard.html` | The Hidden Gem Scorecard dashboard page that displayed it. |
| `pipeline/*.md` | The scheduled task directives that ran the pipeline (`_shared.md`, freeze, snapshot, close, grade), as they stood on Nov 3 2026. |
| `agents-corpus-1.1/` | The fifteen-agent corpus (directives, manifest, brief, lessons, amendments, token log) as it stood before the sprint workflow replaced it on Nov 3 2026. |

Open the pages in a browser. They load fonts from Google Fonts and nothing else; the scorecard needs its original dashboard runtime to show data, so read `picks.json` directly.
